# Хроники Глубинного Трона

Уютная тёмная пиксельная RPG с видом сверху: город Вальмарк днём, семь ярусов древнего королевства под ним — ночью.

* [Дизайн-документ (GDD)](docs/GDD.md)
* [Архитектура](docs/ARCHITECTURE.md)
* [Дорожная карта](docs/ROADMAP.md)

## Запуск

```bash
npm install
npm run dev      # игра на http://localhost:5173
npm test         # юнит-тесты
npm run build    # сборка
npm run e2e      # дымовой тест в браузере (после build)
npm run server   # онлайн-сервер на :2567 (HTTP API + комнаты Colyseus), БД в server-data/
npm run e2e:online  # два браузерных игрока против настоящего сервера (после build)
```

## Онлайн

В главном меню — кнопка «Онлайн». Клиент подключается к `http://<хост>:2567` (адрес можно поменять на экране входа).
Онлайн-герой живёт на сервере: аукцион с живыми игроками, рейтинговая арена (1×1, 3×3, волны, рейды гильдий),
гильдии с казной и территориями и открытое PvP в Пепельных Пустошах. Одиночная игра работает без сервера.
Переменные сервера: `PORT` (по умолчанию 2567), `DB_PATH` (по умолчанию `server-data/dtc.sqlite`).
