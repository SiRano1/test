# Хроники Эльдергарда: Пепел и Луна

Браузерная RPG с открытым миром (Canvas + JS, без зависимостей). Подробное ТЗ: [docs/PROMPT.md](docs/PROMPT.md).

## Запуск
Откройте `index.html` в браузере или выполните `python3 -m http.server` и зайдите на http://localhost:8000.

## Управление
WASD — движение · ЛКМ/Пробел — атака · 1–5 — умения · Q/R/V — зелья · F — расовая способность · E — действие · T — питомец/облик · I C K J M B P L — окна · Esc — меню · F1 — справка.
