# Базарный переполох

Браузерная игра «поиск предметов» в одном файле: откройте `index.html` в браузере (сервер не нужен).

- Огромный рыночный зал (~460 объектов), вся графика рисуется на Canvas.
- Перетаскивание мышью, зум колёсиком 1x–3x (на тачскрине — щипком).
- 12 случайных целей из пула в 24 штуки при каждом запуске, 3 подсказки, сложный режим (−5 сек за промах).

Новые виды объектов добавляются в реестр `DRAW`, новые цели — в массив `TARGET_POOL`.
