# Хроники Глубинного Трона

Уютная тёмная пиксельная RPG с видом сверху: город Вальмарк днём, семь ярусов древнего королевства под ним — ночью.

* [Дизайн-документ (GDD)](docs/GDD.md)
* [Архитектура](docs/ARCHITECTURE.md)
* [Дорожная карта](docs/ROADMAP.md)

## Запуск

```bash
npm install
npm run dev      # игра на http://localhost:5173
npm test         # юнит-тесты
npm run build    # сборка
npm run e2e      # дымовой тест в браузере (после build)
```
